# Project tracking

Skills for keeping the backlog and the sprint in shape: issues, boards,
estimates, standups and sprint ceremonies.

## Skills

- **review-user-story** — scores a user story against the INVEST framework and
  Definition of Ready, and reports whether it is ready for sprint planning.

## What it does

- Reviews a user story's description and acceptance criteria.
- Scores each INVEST criterion (Independent, Negotiable, Valuable, Estimable,
  Small, Testable) on a 1–5 scale and averages them.
- Checks the story against Definition of Ready and gives a ready / not-ready
  verdict, anchored to the average score.

## What it does not do

- It does not write or rewrite the story for you; it flags what to fix.
- It does not change anything in your tracker. You apply the changes yourself.
